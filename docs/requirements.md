# System Requirements

## Roles
- CLIENT
- VOLUNTEER
- A user may have one or both roles.

## Authentication
- Register
- Login
- Logout

## Volunteer
- Update profile
- Select volunteering categories
- Define availability
- Define monthly volunteering-hours goal
- View dashboard
- Approve/reject volunteering requests

## Client
- Update profile
- Search volunteers
- View volunteer details
- Send volunteering request
- View dashboard

## Volunteer Request
Status:
- PENDING
- APPROVED
- REJECTED
- COMPLETED
